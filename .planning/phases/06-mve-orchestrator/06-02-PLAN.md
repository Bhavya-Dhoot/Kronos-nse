```python
class BaseVarianceCollector(ABC):
    def __init__(self, name: str, poll_interval: int = 60, max_errors: int = 5) -> None: ...
    async def fetch(self) -> Any: ...
    def parse(self, raw: Any) -> ParseResult: ...
    def score(self, parsed: ParseResult) -> float: ...
    async def poll(self) -> ParseResult:
        # chains fetch->parse->score, sets normalized, circuit breaker
    @property
    def is_available(self) -> bool: ...
    async def poll_loop(self) -> AsyncIterator[ParseResult]:
        while True:
            yield await self.poll()
            await asyncio.sleep(self.poll_interval)
```
IMPORTANT: poll_loop() is an async generator. It blocks on poll() + sleep() for poll_interval seconds. To cancel it, the asyncio.Task running it must be cancelled.

    **Lifecycle methods:**

    `async def start(self) -> None`:
    - Set `self._running = True`, `self._start_time = time.monotonic()`
    - Determine current market state via `_get_market_state()`
    - For each collector name in `STATE_COLLECTORS[state]`:
      - Create task: `asyncio.create_task(self._run_collector(name))`
      - Store in `self._tasks[name]`
    - Store current state as `self._current_state`
    - Log: "MVE started with {N} collectors in {state} state"

    `async def stop(self) -> None`:
    - Set `self._running = False`
    - Cancel all tasks in `self._tasks.values()`
    - Wait for cancellation: `await asyncio.gather(*self._tasks.values(), return_exceptions=True)`
    - Clear `self._tasks`
    - Log: "MVE stopped"

    `async def _run_collector(self, name: str) -> None`:
    - Per D-18: launch a poll_loop for this collector, but check if the collector is active for the current market state
    - Get collector: `collector = self._collectors[name]`
    - While `self._running`:
      - Check if `name` is in `STATE_COLLECTORS[self._current_state]`:
        - If not active: `await asyncio.sleep(60)` and continue (re-check every 60s) — DON'T cancel the task, just skip polling
        - If active: poll via `result = await collector.poll()`, then call `await self._on_dimension_update(name, result)`, then sleep for `collector.poll_interval`
      - Actually, simpler implementation: run the poll_loop and re-check market state before each poll iteration:

        ```python
            # Always process the result (it was already fetched)

        ```
    - This uses the generator naturally. The collector always polls at its interval regardless of market state, but results are processed through `_on_dimension_update` which could handle stale/ignored dimensions. However, to avoid unnecessary network calls when collectors shouldn't be active, a cleaner approach is:

    ```python
                result = await collector.poll()
                await self._on_dimension_update(name, result)
            await asyncio.sleep(collector.poll_interval)
    ```
