    ```python
    GLOBAL_MARKET_COMBINED_WEIGHT = 0.30   # Combined MVS weight per D-06 (sum of gift_nifty 0.15 + global_macro 0.15)
    GIFT_NIFTY_INTERNAL_WEIGHT = 0.5       # Internal split per D-05

    ```

    **Class: `GlobalDimensionAggregator`**

    `__init__(self, gift_score=None, global_score=None, gift_stale=False, global_stale=False)`:
    - Store all params as instance attributes (matching InstitutionalDimensionAggregator's constructor pattern)
    - These are optional pre-sets for the compute() method

    `compute(self, gift_score=None, global_score=None, gift_stale=False, global_stale=False) -> DimensionScore`:
    - Collect available scores and their weights:
      - If `gift_score is not None`: append score with `GIFT_NIFTY_INTERNAL_WEIGHT` and stale flag
      - If `global_score is not None`: append score with `GLOBAL_MACRO_INTERNAL_WEIGHT` and stale flag
    - If both scores are None: return DimensionScore with score=0.0, is_stale=True, active_weight=0.0
    - Else: compute `combined = sum(s * w for s, w in zip(scores, weights)) / total_weight`
    - `is_stale = any(stales)`
    - `active_weight = total_weight` (sum of available sub-weights)
    - Clamp combined to [-1.0, 1.0], round to 4 decimal places
    - Build detail dict with: gift_score, global_score, gift_stale, global_stale, active_weight, gift_internal_weight, global_internal_weight

    Return template (per D-04 pattern, matching InstitutionalDimensionAggregator):
    ```python
    return DimensionScore(
        name="global_market",
        score=combined,
        weight=GLOBAL_MARKET_COMBINED_WEIGHT,
        is_stale=is_stale,
        detail=detail,
        collected_at=datetime.now(timezone.utc).isoformat(),
    )
    ```

    **The name field is `"global_market"`** (not `"global"` or `"global_macro"`). This matches the config weight entry pattern and is distinct from `"institutional"`.

    **Critical constraints:**
    - Use `DimensionScore` TypedDict return type (not a dataclass)
    - Follow the exact structural pattern of InstitutionalDimensionAggregator (same imports, same error handling, same clamping, same rounding, same detail dict pattern)
    - Use `datetime.now(timezone.utc).isoformat()` for the `collected_at` field
    - **Do NOT** modify InstitutionalDimensionAggregator or any other existing file
    - **Do NOT** import from any collector module — this aggregator is pure math
    - `from __future__ import annotations` at top
    - Module docstring: `"""Global dimension aggregator — combines GIFT Nifty and Global Markets/Macro scores."""` with docstring reference to D-05

    **Scoring edge cases to handle (matching institutional pattern):**
    - Both scores None → score=0.0, is_stale=True, active_weight=0.0
    - One score available → pure that score, active_weight = that sub-weight, is_stale = that sub's stale flag
    - Both available → weighted average by internal weights, is_stale = either stale
    - Clamping: both at 1.0 → 1.0; both at -1.0 → -1.0
    - Stale flags reflected in is_stale (any stale → is_stale=True)
