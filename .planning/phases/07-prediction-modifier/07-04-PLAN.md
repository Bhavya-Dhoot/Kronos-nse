```python
"""Unit tests for PredictionModifier."""
from __future__ import annotations

import pytest
from variance.modifier import PredictionModifier


class MockMVE:
    """Mock MarketVarianceEngine returning controlled MVS dicts."""
    def __init__(self, is_ready: bool = True, last_mvs: dict | None = None):
        self.is_ready = is_ready
        self.last_mvs = last_mvs


def make_mvs(**overrides) -> dict:
    """Build a standard MVS dict with overridable fields."""
    base = {
        "temperature_adjustment": 0.0,
        "directional_bias": 0.0,
        "band_width_multiplier": 1.0,
        "signal_threshold": 0.005,
        "confidence_override": None,
        "composite": 0.0,
        "market_state": "neutral",
        "vix_value": None,
    }
    base.update(overrides)
    return base


def make_prediction(n_bars: int = 12, base_price: float = 22100.0) -> dict:
    """Build a standard prediction dict with n_bars of synthetic data."""
    pred_close = [base_price + i * 2.0 for i in range(n_bars)]
    return {
        "symbol": "NIFTY",
        "pred_open": [base_price - 10 + i * 2.0 for i in range(n_bars)],
        "pred_high": [base_price + 50 + i * 2.0 for i in range(n_bars)],
        "pred_low": [base_price - 50 + i * 2.0 for i in range(n_bars)],
        "pred_close": pred_close,
        "pred_volume": [1000.0 + i * 50 for i in range(n_bars)],
        "pred_timestamps": [f"2024-01-01T09:{15+i}:00" for i in range(n_bars)],
        "temperature": 0.7,
    }
```

**Test Classes and Cases:**

### 1. TestModifyPreInference

**test_noop_when_mvs_not_ready:**
- Create MockMVE(is_ready=False, last_mvs=None)
- modifier = PredictionModifier(mock_mve)
- result = modifier.modify_pre_inference(0.7)
- assert result == pytest.approx(0.7)

**test_standard_adjustment:**
- MockMVS: VIX=20 → temperature_adjustment=0.075
- call with temp=0.7 → expected = max(0.7, 0.7+0.075) = 0.775
- assert result == pytest.approx(0.775)

**test_regime_override_preserved:**
- MockMVS: VIX=20 → temperature_adjustment=0.075
- call with temp=0.85 (VOLATILE regime) → expected = max(0.85, 0.7+0.075) = 0.85
- assert result == pytest.approx(0.85)

**test_mve_overrides_low_regime:**
- MockMVS: VIX=25 → temperature_adjustment=0.15
- call with temp=0.6 (TRENDING regime) → expected = max(0.6, 0.7+0.15) = 0.85
- assert result == pytest.approx(0.85)

**test_capped_adjustment:**
- MockMVS: VIX=35 → temperature_adjustment=0.3 (capped)
- call with temp=0.7 → expected = max(0.7, 0.7+0.3) = 1.0
- assert result == pytest.approx(1.0)

### 2. TestDirectionalBias

**test_bias_decay:**
- MockMVS: directional_bias=0.5, composite=0.5
- pred = make_prediction(n_bars=12)
- modifier = PredictionModifier(MockMVS(True, make_mvs(directional_bias=0.5, composite=0.5)))
- result = modifier.modify_post_inference(pred)
- Bar 0: shift = 0.5 * 1.0 * 0.01 = 0.005 → close *= 1.005
- Bar 11: shift = 0.5 * 0.5 * 0.01 = 0.0025 → close *= 1.0025
- expected_bar0 = 22100.0 * 1.005 = 22210.5
- expected_bar11 = (22100.0 + 22) * 1.0025 = 22122.0 * 1.0025 = 22177.305 (check: bar 11 close = 22100 + 11*2 = 22122)
- Assert close[0] == expected_bar0 and close[11] == expected_bar11
- Also verify pred_open, pred_high, pred_low, pred_volume unchanged from original (bias only affects close per D-10)

### 3. TestBandScaling

**test_bands_widen:**
- MockMVS: VIX=25 → band_width_multiplier=1.08
- pred = make_prediction(n_bars=12)
- original_high = pred["pred_high"][0] (22150.0)
- original_low = pred["pred_low"][0] (22050.0)
- mid = (22150 + 22050) / 2 = 22100
- expected_high = 22100 + (22150-22100) * 1.08 = 22100 + 50 * 1.08 = 22154.0
- expected_low = 22100 - (22100-22050) * 1.08 = 22100 - 50 * 1.08 = 22046.0
- modifier = PredictionModifier(MockMVE(True, make_mvs(band_width_multiplier=1.08, vix_value=25.0)))
- result = modifier.modify_post_inference(pred)
- assert result["pred_high"][0] == pytest.approx(expected_high)
- assert result["pred_low"][0] == pytest.approx(expected_low)

### 4. TestOHLCVConstraints

**test_constraints_enforced:**
- Create prediction where high < max(open, close) after modifications
- MockMVS: no bias, no band scaling (band_width=1.0) — test constraints independently
- pred where high=200, open=210, close=215, low=220
- After constraints: high = max(200, 210, 215) = 215, low = min(220, 210, 215) = 210
- Verify high >= open and high >= close, low <= open and low <= close
- Use a prediction with known constraint violations

**test_volume_non_negative:**
- pred with negative volume
- After modifier: volume >= 0 for all bars
