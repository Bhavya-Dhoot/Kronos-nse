<task type="auto">
  <name>Task 2: Implement modify_post_inference() — bias, bands, constraints, confidence</name>
  <files>variance/modifier.py</files>
  <action>
Add `modify_post_inference(self, prediction: dict) -> dict` method to PredictionModifier.

Per D-18, application order is: **bias → bands → constraints**.

**Layer 1 — Directional Bias (D-10 through D-14):**
- If MVS not ready → return prediction unchanged.
- Extract `directional_bias` from mvs dict (default 0.0).
- Extract `pred_close` list from prediction dict. Must have at least 1 bar.
- N = len(pred_close). For each bar i:
  - `bias_scale = 1.0 - 0.5 * (i / max(N - 1, 1))` per D-12
  - `shift_pct = directional_bias * bias_scale * 0.01` per D-11
  - `pred_close[i] = pred_close[i] * (1.0 + shift_pct)` per D-13
- Only pred_close is modified (D-10). Open, High, Low, Volume unchanged.
- D-14 example: composite=+0.5, pred_len=12. Bar 0: shift=0.5*1.0*0.01=0.005→+0.5%. Bar 11: shift=0.5*0.5*0.01=0.0025→+0.25%.
- Log at DEBUG: `"Bias: composite={bias:.3f}, shift range [{min:.4f}, {max:.4f}]"`

**Layer 2 — Band Scaling (D-15 through D-16):**
- Extract `band_width_multiplier` from mvs dict (default 1.0).
- For each bar i:
  - `mid = (pred_high[i] + pred_low[i]) / 2` per D-15
  - `new_high = mid + (pred_high[i] - mid) * band_width_multiplier`
  - `new_low = mid - (mid - pred_low[i]) * band_width_multiplier`
  - Clamp new_low to minimum 0 (prices can't be negative).
- Update `pred_high[i]` and `pred_low[i]` in the dict.

**Layer 3 — OHLCV Constraints (D-17):**
After bias and bands, enforce for each bar i:
- `pred_high[i] = max(pred_high[i], pred_open[i], pred_close[i])` — high is highest
- `pred_low[i] = min(pred_low[i], pred_open[i], pred_close[i])` — low is lowest
- If high < low after clamping → set high = low (safety, should not happen given the max/min logic above)
- `pred_volume[i] = max(pred_volume[i], 0.0)` — volume non-negative
- Log at DEBUG if any bar was clipped: `"OHLCV constraints clipped {n} bars"`

**Layer 4 — Confidence Override (D-19 through D-21):**
- Extract `confidence_override` from mvs dict.
- If not None: set `prediction["mve_confidence"] = confidence_override`.
- If None: ensure `"mve_confidence"` is NOT in prediction or set to None (clean state).
- Per D-21: Direction is NOT affected — only confidence is overridden.

**Return the modified prediction dict.**

**Edge cases handled by this method (all are within Claude's discretion per CONTEXT.md):**
- Empty pred_close list → return prediction unchanged
- pred_high/pred_low missing keys → return prediction unchanged (defensive)
- Any list length mismatches → process up to min length, log warning
- All float operations use Python native floats (no numpy dependency needed for modifier.py)
