    ### TestFetch (3-4 tests)
    - `test_fetch_calls_browser` — Mock `_get_browser`, return a mock page. Verify fetch calls `page.goto()`, extracts value, closes page. Assert return dict has `value` and `source` keys.
    - `test_fetch_fallback_on_primary_failure` — Mock primary scrape to fail (raise ValueError or return no value). Verify fallback URL is tried. Assert `source` is `"niftytrader"`.

    ### TestParse (3-4 tests)
    - `test_parse_with_gap` — Mock `_get_angel_client().get_previous_close()` to return 23500.0. Call `parse({"value": 23523.5, "source": "groww", "url": "..."})`. Verify:
      - `raw_value == 23523.5`
      - `detail["gap_pct"] == pytest.approx(0.1, abs=0.01)` → (23523.5 - 23500.0) / 23500.0 * 100
      - `direction == 1`
      - `source == "groww"`
    - `test_parse_negative_gap` — prev_close=23500.0, gift_nifty=23265.0. Verify gap ≈ -1.0%, direction = -1
    - `test_parse_no_prev_close` — Mock `get_previous_close()` to return `None`. Verify `detail["gap_pct"]` is `None` and `raw_value` is still set (D-07).
    - `test_parse_zero_gap` — prev_close=23500.0, gift_nifty=23500.0. Verify gap ≈ 0.0, direction = 0

    ### TestScore (3+ tests — use @pytest.mark.parametrize)
    - Parametrized test with anchor points per D-06:
      ```python
      @pytest.mark.parametrize("gap_pct,expected_score", [
          (0.0, 0.0),
          (1.0, 0.5),
          (2.0, 1.0),
          (-1.0, -0.5),
          (-2.0, -1.0),
          (3.0, 1.0),    # clamped
          (-3.0, -1.0),  # clamped
          (0.5, 0.25),
      ])
      def test_score_formula(self, collector, gap_pct, expected_score):
          parsed = collector.parse({
              "value": 23500.0 + (gap_pct * 23500.0 / 100) if gap_pct != 0 else 23500.0,
              "source": "groww",
              "url": "https://groww.in/markets/gift-nifty",
          })
          score = collector.score(parsed)
          assert score == pytest.approx(expected_score, abs=0.01)
      ```
    - `test_score_no_gap_returns_zero` — Mock prev_close to return None, verify score returns 0.0 (D-07)
    - *(Optional)* `test_score_zero_when_gap_pct_none_in_detail` — Direct test of score() with parsed result that has `detail = {"gap_pct": None}`
