**Module structure:**
```python
"""Variance MVS API endpoints."""

from __future__ import annotations

import logging
from typing import Any

from fastapi import APIRouter, Request

from api.schemas import (
    DimensionDetailResponse,
    DimensionScoreSchema,
    VarianceHistoryResponse,
    VarianceScoreResponse,
)

logger = logging.getLogger(__name__)

router = APIRouter(prefix="/variance", tags=["variance"])
```

**Endpoints:**

1. **GET /variance/score** — `get_variance_score(request: Request) -> VarianceScoreResponse | Response`
   - Access MVE via `request.app.state.mve`
   - If `mve is None or not mve.is_ready`: return `Response(status_code=204)` (NOT 200 with null — per API-01 exact requirement)
   - Get `last_mvs` dict from `mve.last_mvs`
   - If `last_mvs` is None: return 204
   - Map dict to `VarianceScoreResponse` (dimensions are stored as list of dicts in the dict)
   - response_model_exclude_unset=True not needed; use explicit mapping
   - Return type: `Union[VarianceScoreResponse, Response]` — use `from fastapi import Response`

2. **GET /variance/dimensions/{name}** — `get_dimension_detail(name: str, request: Request) -> DimensionDetailResponse`
   - Valid dimension names: "vix", "options", "fii_dii", "oi", "gift_nifty", "global_markets", "macro"
   - Access `request.app.state.mve` — if None, raise 404
   - Check `mve._scores` dict for the dimension name (the private `_scores` dict is the source of truth for per-dimension data)
   - If name not in `mve._scores`: raise `HTTPException(status_code=404, detail=f"Dimension '{name}' not found")`
   - Build `DimensionDetailResponse` from the ScoreEntry dict
   - For `raw_value`: look up the collector's last result. If not available, set None.

3. **GET /variance/history** — `get_variance_history(request: Request) -> VarianceHistoryResponse`
   - Access MVE Redis via `request.app.state.mve_redis`
   - If `mve_redis is None`: return `VarianceHistoryResponse(entries=[], total=0)`
   - Use `mve_redis._client.lrange("mve:mvs:history", 0, -1)` to get all entries
   - Parse each entry from JSON string to dict, map to `VarianceScoreResponse`
   - Include `total` count
   - Wrap in try/except — on Redis error, return empty response with logger.warning

**Important details per D-07 (Claude's discretion):**
- The `_scores` dict on MarketVarianceEngine is `dict[str, ScoreEntry]` where ScoreEntry has `{score, weight, is_stale, first_poll, collected_at}`. Access via `mve._scores` (yes, this is a private attribute — it's the established pattern in the codebase).
- For the history route, use `mve_redis._client.lrange(...)` since RedisCache doesn't have a dedicated list method. This follows the project's pattern of accessing `_client` directly when needed. Add a future note about extracting this to a helper.
- Use `import json` for parsing history JSON strings.
