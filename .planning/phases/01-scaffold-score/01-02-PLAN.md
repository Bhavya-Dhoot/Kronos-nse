    Create `variance/score.py` implementing:

    **Imports:**
    ```python
    from __future__ import annotations
    from dataclasses import dataclass, field
    from datetime import datetime, timezone
    from enum import Enum
    from typing import Any

    from variance.schemas import DimensionScore
    ```

    **`MarketState` Enum** with values per D-16:
    - `PANIC` — VIX > 28
    - `FEAR` — VIX > 22 and composite < -0.4
    - `UNCERTAIN` — VIX between 14 and 22 (inclusive) and composite between -0.4 and 0.4
    - `BULL_RUN` — VIX < 14 and composite > 0.4
    - `NEUTRAL` — everything else

    State precedence order: check FEAR first (most restrictive), then PANIC, then BULL_RUN, then UNCERTAIN, else NEUTRAL.

    **`@dataclass` MarketVarianceScore:**
    Fields:
    - `dimensions: list[DimensionScore]` — all active dimension scores
    - `composite: float` — computed weighted composite (-1.0 to 1.0)
    - `market_state: MarketState` — classified per D-16
    - `vix_value: float | None` — current VIX value for modification calculations
    - `created_at: str` — ISO 8601 timestamp

    **`@classmethod` `build(dimensions: list[DimensionScore], vix_value: float | None = None) -> MarketVarianceScore`**:
    1. Compute composite: sum of (score * weight) for all dimensions. For dimensions where `is_stale=True`, halve the weight (D-17: stale dimensions get half weight).
    2. The denominator is the sum of effective weights (to normalize even with stale dimensions).
    3. Clamp composite to [-1.0, 1.0].
    4. Classify market state using D-16 rules.
    5. Return instance with created_at = current UTC ISO 8601.

    **Derived Properties** (per D-15):
    - `temperature_adjustment -> float`:
      If vix_value is None: return 0.0
      If vix_value > 15: return min((vix_value - 15) * 0.015, 0.3)
      Else: return 0.0
      (0.015/VIX point above 15, capped at +0.3)

    - `directional_bias -> float`:
      Returns the composite score. Interpretation: positive = bullish bias, negative = bearish bias.
      Full value at bar 0, decays to 50% at last bar (decay logic lives in PredictionModifier — here we just expose the bias value).

    - `band_width_multiplier -> float`:
      If vix_value is None or vix_value <= 15: return 1.0
      Return 1.0 + (vix_value - 15) * 0.008
      (0.8% wider per VIX point above 15)

    - `signal_threshold -> float`:
      Base 0.005 (0.5%) + 0.0002 (0.02%) per VIX point above 15.
      If vix_value is None or vix_value <= 15: return 0.005
      Return 0.005 + (vix_value - 15) * 0.0002

    - `confidence_override -> str | None`:
      Based on market_state:
      - PANIC or FEAR → return "LOW"
      - UNCERTAIN and abs(composite) < 0.5 → return "LOW" (downgrade one level — downstream should handle)
      - Otherwise → return None

    **Method: `to_dict() -> dict[str, Any]`** — JSON-serializable dict with all fields including derived properties.
  </action>
