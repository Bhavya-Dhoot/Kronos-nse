    **Imports:**
    ```python
    from __future__ import annotations

    import asyncio
    import logging
    from abc import ABC, abstractmethod

    ```

    **class BaseVarianceCollector(ABC):**
    
    Constructor: `__init__(self, name: str, poll_interval: int = 60, max_errors: int = 5)`
    - `self.name` — dimension name (e.g., "vix", "options")
    - `self.poll_interval` — seconds between polls (default 60)
    - `self._max_errors` — consecutive errors before circuit-breaker (default 5 per D-13)
    - `self._consecutive_errors: int = 0`
    - `self._last_successful_result: ParseResult | None = None` — for stale returns (D-14)
    - `self._last_poll_time: datetime | None = None`
    - `self._logger = logging.getLogger(f"{__name__}.{name}")`

    **Abstract methods:**
    1. `@abstractmethod async def fetch(self) -> Any:` — Fetch raw data from external source.
       Per D-12: sync library calls (NseIndiaApi, yfinance) are wrapped in `asyncio.to_thread()` by the subclass.

    2. `@abstractmethod def parse(self, raw: Any) -> ParseResult:` — Parse raw data into ParseResult.
       This is NOT async — parsing is CPU-bound data transformation.

    3. `@abstractmethod def score(self, parsed: ParseResult) -> float:` — Score the parsed result.
       Returns normalized value in [-1.0, 1.0]. NOT async.

    **Concrete methods:**

    4. `async def poll(self) -> ParseResult:` — Full poll cycle:
       1. Call `await self.fetch()`
       2. Call `self.parse(raw)`
       3. Call `self.score(parsed)` — add score to the ParseResult, set normalized field
       4. Update `_last_successful_result` and `_last_poll_time`
       5. Reset `_consecutive_errors` to 0
       6. Set `as_of` to current UTC ISO timestamp
       7. Return the ParseResult
       
       If ANY step raises:
       - Increment `_consecutive_errors`
       - Log error at WARNING level
       - If `_last_successful_result` exists:
         - Copy it, set `is_stale=True`, update `as_of` to current time
         - Return the stale copy (D-14)
       - Else: raise (no cached value available)

    5. `@property def is_available(self) -> bool:` — Returns `_consecutive_errors < max_errors`.
       Once `_consecutive_errors >= max_errors`, returns False until a successful poll resets it.

    6. `async def poll_loop(self) -> AsyncIterator[ParseResult]:` — Infinite async generator:
       ```python
       async def poll_loop(self) -> AsyncIterator[ParseResult]:
           while True:
               result = await self.poll()
               yield result
               await asyncio.sleep(self.poll_interval)
       ```

    Add to `variance/__init__.py`:

