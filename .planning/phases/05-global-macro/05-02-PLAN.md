<objective>
Build the MacroCollector — polls 4 macro tickers (USD/INR, Brent crude, Gold, US 10Y) via yfinance every 5 minutes, computes weighted average, then inverts it (all macro = inverse for India) and clamps to [-1, 1].

Purpose: Macroeconomic indicators directly impact Indian markets. USD/INR strength means FII outflows (bearish), rising crude increases India's import bill (bearish), rising gold signals risk-off (bearish), rising US 10Y yields make EM less attractive (bearish). All four are inverse — when they go up, India goes down.

Output: variance/collectors/macro_collector.py, updated __init__.py, updated config/base.yaml

    ```python
    def _to_float(value: Any) -> float | None:
        """Safely convert a value to float, returning None on failure."""
        if value is None:
            return None
        try:
            return float(value)
        except (TypeError, ValueError):
            return None
    ```

    ```python
    def _compute_change_pct(ticker: str) -> dict[str, Any]:
        """Fetch 5d history and compute change_pct from latest vs previous close.
        
        Per D-11/D-14: change_pct = (latest_close - prev_close) / prev_close * 100
        """
        import yfinance as yf
        try:
            t = yf.Ticker(ticker)
            df = t.history(period="5d")
            if df.empty or len(df) < 2:
                return {"error": f"Insufficient data: {len(df)} rows"}
            closes = df["Close"].values
            prev_close = _to_float(closes[-2])
            latest_close = _to_float(closes[-1])
            if prev_close is None or latest_close is None or prev_close == 0:
                return {"error": "Invalid close values"}
            change_pct = (latest_close - prev_close) / prev_close * 100.0
            return {"change_pct": round(float(change_pct), 4)}
        except Exception as e:
            return {"error": str(e)}

    Per D-19: NaN/None/Inf close values result in error return via _to_float, exclusion from weighted avg, and weight renormalization.
    ```

    **Class: `MacroCollector(BaseVarianceCollector)`**

    - Per D-01: iterate through `self._tickers` keys sequentially
    - For each ticker: `await asyncio.to_thread(_compute_change_pct, ticker)`
    - Per D-02: catch exceptions per ticker — one failure doesn't block others
    - Return dict: `{ticker: result_dict, ...}`

    `def parse(self, raw: dict[str, Any]) -> ParseResult`:
    - Same logic as GlobalMarketsCollector.parse() but with MACRO_TICKERS
    - Separate successful vs failed tickers
    - Per D-17: renormalize weights for successful tickers
    - Compute `weighted_sum = sum(change_pct[t] * renorm_weight[t])`
    - Direction: sign of `-(weighted_sum)` — note the inversion for direction
    - Magnitude: `min(1.0, abs(weighted_sum))` — magnitude before inversion
    - Per D-18: if no successful tickers → return ParseResult with raw_value=0.0, direction=0
    - Include in detail: `"inverted": True` to indicate this score will be negated
    - Set `raw_value` to `weighted_sum` (the pre-inversion value) — the score() method handles the negation
    - Per-ticker detail: for each ticker show change_pct, weight, renorm_weight, status

    `def score(self, parsed: ParseResult) -> float`:
    - Per D-15/D-16: `weighted_avg = parsed["raw_value"]; return max(-1.0, min(1.0, -weighted_avg))`
    - The negation (`-weighted_avg`) applies the all-inverse rule
    - Clamping ensures output stays in [-1.0, 1.0]

    **Scoring verification example from CONTEXT.md:**

    ```
    USDINR=X: +0.3% → 0.3*0.35 = 0.105

    Score = -0.35 (inverted), clamped to [-1, 1] = -0.35
    ```
