<objective>
Build the GlobalMarketsCollector — polls 8 global tickers (US futures, Asian indices, DXY) via yfinance every 5 minutes, computes weighted average with DXY as inverse modifier, and produces a clamped [-1, 1] score.

Purpose: Global market sentiment is a leading indicator for NSE. US futures move while NSE is closed (overnight session), and Asian indices provide regional context. DXY (US Dollar Index) has an inverse relationship with emerging markets — a strong USD typically means NSE headwinds. This collector captures that dynamic with a single [-1, 1] score.

    **Static helper (`_compute_change_pct`):**
    - Synchronous function (runs in `asyncio.to_thread`)
    - Input: ticker symbol string
    - Creates `yf.Ticker(ticker)`, calls `ticker.history(period="5d")` per D-11
    - Extracts last 2 closes from DataFrame: `closes = df["Close"].values`
    - Returns `{"change_pct": float}` on success
    - Returns `{"error": str}` on failure (empty DataFrame, bad values, network error, yfinance exception)
    - Per D-19: missing/NaN/None close values are treated as errors — `_to_float` returning None triggers error return
    - Use `_to_float()` helper for safe conversion of close values

    **Helper function renaming avoidance:** follow FIIDIICollector's pattern of a module-level `_to_float` static-ish function (not a class method) — this is used inside `_compute_change_pct` which runs in a thread pool and should not reference `self`.

    **Class: `GlobalMarketsCollector(BaseVarianceCollector)`**

    `__init__()`:
    - Call `super().__init__(name="global_markets", poll_interval=300)`
    - Store a copy of `GLOBAL_TICKERS` as `self._tickers` for renormalization math

    `async def fetch(self) -> dict[str, Any]`:
    - Per D-01: iterate through `self._tickers` keys sequentially
    - For each ticker: `await asyncio.to_thread(_compute_change_pct, ticker)`
    - Per D-02: catch exceptions per ticker — one failure doesn't block others
    - Return dict: `{ticker: result_dict, ...}` where result_dict is either `{"change_pct": ...}` or `{"error": ...}`

    `def parse(self, raw: dict[str, Any]) -> ParseResult`:
    - Separate successful tickers (have `"change_pct"` key) from failed (have `"error"` key)
    - Per D-17: if any tickers failed, compute weight renormalization:
      - `successful_abs_sum = sum(abs(self._tickers[t]) for t in successful)`
      - `all_abs_sum = sum(abs(w) for w in self._tickers.values())`
      - `renorm_factor = all_abs_sum / successful_abs_sum` (when all tickers succeed = 1.0)
      - `renorm_weight[t] = self._tickers[t] * renorm_factor`
    - Compute `weighted_sum = sum(successful[t] * renorm_weight[t] for t in successful)`
    - Direction: `1 if weighted_sum > 0 else (-1 if weighted_sum < 0 else 0)`
    - Magnitude: `min(1.0, abs(weighted_sum))`
    - Per D-18: if no successful tickers → return ParseResult with raw_value=0.0, direction=0, magnitude=0.0, detail={"note": "all tickers failed"}
    - Build per-ticker detail dict in parse result showing each ticker's change_pct, weight, and status

    `def score(self, parsed: ParseResult) -> float`:
    - Per D-12/D-13: `return max(-1.0, min(1.0, parsed["raw_value"]))`
    - This clamps the weighted average (which already includes DXY's -10% inverse) to [-1.0, 1.0]

    **Scoring verification example from CONTEXT.md:**
    ```
    ES=F: +0.5% → 0.5*0.30 = 0.15
    NQ=F: +0.8% → 0.8*0.20 = 0.16
    YM=F: +0.3% → 0.3*0.10 = 0.03
    N225: -0.2% → (-0.2)*0.15 = -0.03
    HSI: -1.0% → (-1.0)*0.12 = -0.12
    SH: -0.5% → (-0.5)*0.08 = -0.04
    KS11: +0.1% → 0.1*0.05 = 0.005
    DXY: +0.2% → 0.2*(-0.10) = -0.02
    Total: 0.135 → clamped = 0.135
    ```

| T-05-02 | I | yfinance history | mitigate | No API keys, no credentials, no PII transmitted. yfinance makes public HTTP requests to Yahoo Finance — no sensitive data at risk. |
| T-05-03 | D | Yahoo rate limiting | accept | Sequential per-ticker calls (not concurrent) naturally throttle request rate. If Yahoo blocks, all tickers fail → per D-18 score returns 0.0. Circuit breaker in base class stops retries after 5 failures. |
| T-05-04 | T | NaN/Inf closes in yfinance data | mitigate | _compute_change_pct uses _to_float() to safely convert close values. NaN, None, or Inf values result in error return, triggering per-ticker exclusion per D-17. |
